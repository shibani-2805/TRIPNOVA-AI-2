About TripNova

Explore More, Travel Smarter

TripNova is a college project that turns a Python trip-planner into a full website. You choose what matters, and it builds a clear, day-wise itinerary you can read, print and save.

It is built with Python Flask, SQLite, HTML, CSS and JavaScript.

What is rule-based and what is AI?

We keep this clear, so you know exactly what you are using.

  • Rule-based Itinerary building, activity and attraction selection, hotel and meal suggestions, cost calculation. These follow fixed rules in Python and data tables. There is no AI model involved.
  • Live data Weather forecast (Open-Meteo, up to 15 days ahead) and exchange rates. These are real data services, not AI. If they are unreachable, the site falls back to seasonal estimates and fixed approximate rates, and says so.
  • Real AI (optional) The "AI trip brief" on a saved trip calls an AI API. It only works when the site owner adds an API key.
